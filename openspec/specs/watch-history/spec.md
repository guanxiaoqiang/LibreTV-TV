# watch-history Specification

## Purpose

观看历史能力：记录用户看过或正在看的每一集及其播放位置，在首页提供“继续观看”与历史列表，支持删除单条与清空，并保证已看完的影片下次从头播放。

## Requirements

### Requirement: 历史记录写入
系统 SHALL 以“来源 + 影片 ID + 线路索引 + 剧集索引”为键记录观看条目；当影片 ID 缺失时，退化为“标题 + 剧集名 + 播放地址”作为键。

#### Scenario: 写入一条历史
- **WHEN** 播放过程中回报了新的播放位置
- **THEN** 对应条目被新增或更新，并成为历史列表中最新的记录

#### Scenario: 缺少影片 ID 的键
- **WHEN** 播放请求没有影片 ID
- **THEN** 系统使用标题、剧集名与播放地址组合作为唯一键

### Requirement: 历史容量与排序
系统 SHALL 限制历史条数上限，并按更新时间倒序排列。

#### Scenario: 超出上限
- **WHEN** 历史记录数量超过上限
- **THEN** 最旧的记录被丢弃，保留最近的若干条

### Requirement: 已看完自动归零
系统 SHALL 在记录时判断是否已看完（播放位置达到总时长的 95% 及以上）；已看完的条目 SHALL 把播放位置归零。

#### Scenario: 看完一集
- **WHEN** 用户播放到片尾并上报接近总时长的位置
- **THEN** 历史条目被保存为从零开始，下次打开该集从头播放

### Requirement: 继续观看与历史展示
系统 SHALL 在首页提供历史入口，展示历史条目的标题、海报、观看位置与进度百分比，并支持删除单条与清空全部。

#### Scenario: 进度百分比
- **WHEN** 历史条目记录的时长大于零
- **THEN** 卡片上显示 0 至 100 的进度百分比

#### Scenario: 删除单条
- **WHEN** 用户在历史页删除一条记录
- **THEN** 该记录立即从列表与本地存储中移除

#### Scenario: 清空全部
- **WHEN** 用户清空全部历史
- **THEN** 所有历史记录被删除，首页历史入口不再显示条目

### Requirement: 历史状态实时同步
系统 SHALL 以可观察流的形式暴露历史列表，使播放中的进度回报能即时反映到界面。

#### Scenario: 播放后首页立即更新
- **WHEN** 播放结束后返回首页
- **THEN** 历史列表已包含刚才的观看记录，无需重启应用
